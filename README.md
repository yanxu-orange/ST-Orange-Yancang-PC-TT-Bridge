# 砚藏 PC 联动

供 TauriTavern 2.4.0 与含 TT 联动功能的砚藏 PC 使用。当前配套程序为本地测试版，公开砚藏 PC 0.2.0 尚不包含联动功能。安卓扩展继续使用原仓库。

## 安装与连接

1. 在 TT 打开「扩展 → 安装扩展」，粘贴下方链接，安装后重载 TT。分支名留空。

   `https://github.com/yanxu-orange/ST-Orange-Yancang-PC-TT-Bridge`

2. 在砚藏「设置 → TauriTavern」启用联动，再到 TT「砚藏 PC 联动」点击「启用 PC 联动」。
3. 首次回到砚藏点击「允许连接」。以后两边运行时自动连接，暂时断开后后台重连，无需粘贴连接码。

已安装的扩展可在 TT 扩展管理中更新。导出的 ZIP 仅供手动安装备用，不能粘贴到 TT 的扩展安装窗口。

已装过手动 PC 测试扩展时，先停用旧 PC 扩展并重载 TT，再用链接安装。安卓扩展无需停用。

## 传送角色卡

砚藏角色详情的「发送至 TT」发送当前版本与卡面，在 TT 点击「确认接收为新角色」。砚藏的「导入 → TauriTavern」可勾选 TT 角色，接收后进入原导入预览，确认后入库。

关闭联动可停止连接；解除连接会移除已记住的授权。不会自动删除、覆盖或同步角色卡，不调用模型。

此 PC 扩展在 TT 自身设置中保存本机设备凭据；TT 扩展共享同一宿主信任范围。凭据不放入角色卡、日志或导出 ZIP。
